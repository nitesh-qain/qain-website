## Research findings
Web search on current LLM/agent testing practice to ground the post:
- **Deterministic checks first, judge model second** — run cheap code-based checks before reaching for LLM-as-a-judge; reserve the judge for qualitative questions a rule can't grade. ([DigitalOcean](https://www.digitalocean.com/resources/articles/llm-as-a-judge), [Mastra](https://mastra.ai/articles/llm-as-a-judge))
- **Judge calibration** — an LLM-as-a-judge setup needs validation against human-labeled examples and ongoing drift monitoring, with known position/verbosity biases mitigated by randomized ordering and cross-provider judges. ([Openlayer](https://www.openlayer.com/blog/llm-as-judge-evaluation-guide), [Arize](https://arize.com/blog/when-to-use-llm-as-a-judge/))
- **Agents need step-level grading** — a single agent task can involve 20–60 model calls before a final answer; final-answer-only checks miss wrong tool calls that still land on a plausible output. ([DigitalOcean](https://www.digitalocean.com/resources/articles/llm-as-a-judge))
- **Non-determinism** — run each case multiple times and compare an averaged score against a tolerance band rather than trusting a single run; one source citing Anthropic's own eval research puts single-run agent success rates around 68–74%. ([FrugalTesting](https://www.frugaltesting.com/blog/how-to-test-non-deterministic-ai-features-in-production-a-practical-framework-for-qa-teams), [Built In](https://builtin.com/articles/ai-testing-framework-engineers))
- **Prompt/model regression** — version-control prompts like code, run the eval suite before a prompt or model change ships, snapshot the rendered prompt and diff it against a baseline. ([Channel](https://www.channel.tel/blog/agent-regression-testing-ci-cd-pipeline), [tianpan.co](https://tianpan.co/blog/2026-04-15-agent-test-pyramid-llm-testing))
- **Flagged, not used as fact**: a March 2026 arXiv preprint (AgentAssay, [2603.02601](https://arxiv.org/abs/2603.02601)) claims 78–100% cost reduction and 86% behavioral detection power for its regression-testing approach — single-author, self-reported numbers, not independently verified. Cited in the post explicitly as a research direction to watch, not a settled figure.
- Competitor scan: the "AI/LLM testing" service-page space is already crowded (QATestLab, QASource, DeviQA, Qawerk, TestDevLab, Testlio all have dedicated pages/pitches), mostly vendor-authored "top 10" comparison content. Reinforces that an honest, cited, approach-led page (ours) differentiates from the self-promotional pack rather than competing on claimed outcomes.
